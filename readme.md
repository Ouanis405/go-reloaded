# Go-Reloaded

## Description
Go-Reloaded est un outil de traitement de texte écrit en Go. Il prend en entrée un fichier texte et applique automatiquement plusieurs corrections et transformations de texte (conversions hexadécimales/binaires, gestion de la casse, correction de la ponctuation et ajustement des articles "a/an").

## Utilisation

Pour exécuter le programme, lancez la commande suivante dans le terminal :

```bash
go run . <fichier_entree.txt> <fichier_sortie.txt>
